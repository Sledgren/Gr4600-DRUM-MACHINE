# GR4600

GR4600 is a standalone browser music workstation/player. Open `index.html` locally or host the contents of this folder with GitHub Pages.

## GitHub Pages

1. Create or open the GitHub repository.
2. Upload everything in this folder so `index.html` is at the repository root.
3. Commit the upload.
4. In Settings > Pages, publish from the `main` branch and `/ (root)`.

Do not upload the outer folder as an extra nested directory. GitHub Pages must see `index.html`, `app.js`, `style.css`, and `assets` at the top level.

## Local launch

Double-click `index.html`. For the most reliable sample loading, run the folder through a basic local web server.
